# GRAVLASSO

A single-file HTML5 Canvas **asteroid arena** game with a gravity lasso twist.

**Genre:** Top-down arena survival.
**Twist:** You have **no guns**. Your only weapon is a **GRAVITY LASSO** — hold
`Space` to pull the nearest asteroid toward you, aim with the mouse, then release
to fling it. Hurl rocks into other rocks for chain explosions, or send them straight
into enemy drones. Every kill without taking a hit grows your **COMBO multiplier**,
so stringing flings together is both the safest and most lucrative play.
**Controls:** `WASD` / Arrows = thrust · Mouse = aim · `Space` hold/release = lasso ·
`Esc` / `P` = pause · `M` = mute.
**Goal:** Survive escalating waves (enemy drones join from Wave 3), build combos,
chase the high score. Three lives — game ends when all are lost.

## Run it

One self-contained file — **no dependencies, no build step**:

```
open gravlasso/index.html
```

Or from the arcade hub:

```
open index.html
```
